# Minsk Coffee Charm

Create a premium responsive one-page restaurant website for a small specialty coffee shop in Minsk. The target audience is 20–35 year old urban customers. The visual identity should feel warm, minimalist and premium rather than generic. Prioritize mobile-first design, menu readability, location, opening hours and a strong reservation CTA. Use the restaurant's actual brand colors, public menu information and publicly available photos. Do not invent awards, reviews, prices or business facts.
